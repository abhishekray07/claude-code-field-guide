# Contributing

We welcome contributions. This repo is opinionated and data-backed, so we have a few guidelines.

## What we're looking for

- **Findings with data.** "I measured X and found Y." Include your methodology, sample size, and Claude Code version.
- **Configs that work.** Tested in real projects, not hypothetical. Include what problem it solves and any gotchas.
- **Tool recommendations you've actually used.** Not "this looks cool" but "I used this for 2 weeks and here's what happened."
- **Before/after showcases.** Show the difference a config or workflow change made. Screenshots, token counts, timing data.

## What we don't need

- Link dumps without opinions
- Untested configs
- Marketing language
- Findings without methodology or version info

## How to submit

1. Fork the repo
2. Add your contribution to the appropriate section
3. Include a "Verified with Claude Code vX.Y.Z on YYYY-MM-DD" tag
4. Open a PR with a clear description of what you found and how

## Freshness

Every finding in this repo has a version tag. If you notice something is outdated, open an issue or PR with updated data. That's one of the most valuable contributions you can make.

## Questions?

Open an issue. We're friendly.
